Pin de mapa: núcleo dourado pulsante (20px) + etiqueta com nome. O núcleo do destino leva `data-fio-end`, que é onde a rota do fio da navalha termina.

```jsx
<MapPin label="Sujeito Homem" sublabel="Jales, SP" />
<MapPin variant="origin" label="Você" />
```

Sem teardrop desenhado: o pin é círculo + halo. Mapa de fundo é sempre real (tiles escuros) ou placeholder listrado — nunca ilustração inventada.
