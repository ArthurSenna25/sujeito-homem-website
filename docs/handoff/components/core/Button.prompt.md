Botão do Sujeito Homem: primário em ouro (a ação principal, uma por tela) e secundário em contorno.

```jsx
<Button icon="calendar" iconAfter="arrow-right">Agendar horário</Button>
<Button variant="secondary" icon="navigation">Como chegar</Button>
<Button loading>Enviando</Button>
<Button iconOnly variant="secondary" icon="message-circle" aria-label="WhatsApp" />
```

Estados: hover (ouro claro + brilho), foco (anel dourado), ativo (afunda 1px), desabilitado, carregando (linha de luz). Tamanhos sm 36 · md 44 · lg 56.
